# 30-секундное видео: раскадровка

Формат: 1080×1920 для Reels/Shorts и 1920×1080 для сайта.  
Тон: спокойный, без «революции». Показываем экран, а не говорящую голову.

| Время | Кадр | Действие | Текст на экране |
| --- | --- | --- | --- |
| 0–3 с | Пустая библиотека | Курсор на «Добавить папку» | «Calibre слишком сложен?» |
| 3–7 с | Выбор папки | Появляются 5 обложек | «Просто добавьте книги» |
| 7–11 с | Двойной клик по обложке | Открывается читалка | «FB2, EPUB, PDF, TXT» |
| 11–16 с | Выделение текста | Панель: словарь, заметка | «Словарь и заметки — по выделению» |
| 16–20 с | Окно словаря | Переключение «офлайн» | «Работает без интернета» |
| 20–24 с | Главная | Кнопка «Продолжить» | «Возвращайтесь к книге в один клик» |
| 24–27 с | Боковая панель | Включение «Только чтение» | «Без каталогов и статистики» |
| 27–30 с | Логотип + кнопка | Ссылка на сайт | «Читалка. Просто читать.» |

## Титры для соцсетей

**Короткий:** «Читалка для Windows: FB2, EPUB, PDF, TXT. Без сложности Calibre.»

**Средний:** «Добавили книги — читаете. Офлайн-словарь, заметки и режим
„Только чтение“ для тех, кому нужна просто читалка.»

## Что нужно для съёмки

- чистый профиль с демо-книгами;
- окно 1440×900, тёмная тема;
- заранее открытая книга на 3–4 странице;
- запись экрана 60 fps;
- без уведомлений и лишних окон.
